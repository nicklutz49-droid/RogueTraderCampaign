# LORE INDEX — THE VHARADAN LEGACY

Pre-established GM canon for the campaign: dynasty history, NPC backstories
and secrets, factions, worlds, and the deep truths of the Hesperus Reach.

**Canon precedence.** `state/` records what has actually happened and been
revealed in play — it ALWAYS wins on current facts. `lore/` holds background
canon and GM secrets not yet revealed. If they ever conflict, state wins and
the lore file should be corrected. When play establishes significant new
background canon, extend the relevant lore file (per `CLAUDE.md`).

**Spoiler convention.** Every file carrying unrevealed canon opens with a
canon-status notice; deep secrets live under a clearly marked `## GM secrets`
heading at the end of each file. The GM (Claude) must never volunteer
GM-secret content to the player before play reveals it — let the files'
pacing guidance set the speed. Each file ends with a `## Hooks` section:
concrete ways its material enters play.
