# The Vharadan Legacy

An ongoing Warhammer 40,000 Rogue Trader narrative campaign, run by Claude as
Game Master. The player is **Lord-Captain Aurelian Vharadan**, ex-Guard
colonel and usurper of a 3,000-year-old Warrant of Trade, building an
independent military power in the newly opened **Hesperus Reach**.

## How to play

Open a Claude session in this repo and say hello — `CLAUDE.md` instructs the
GM to read the campaign state, recap "Previously...", and resume exactly where
play stopped. Say "save and stop" to end a session with a full log entry.

## Repository layout

| Path | What it is |
|---|---|
| `CLAUDE.md` | GM instructions: premise, tone, mechanics, file protocols |
| `state/` | **The record of play** — always current, always wins |
| `state/campaign_log.md` | Canonical session-by-session log |
| `state/character_sheet.md` | The Lord-Captain: traits, gear, wounds, threads |
| `state/dynasty_ledger.md` | Dynasty meters, fleet, forces, holdings, debts |
| `state/npcs.md` | NPC roster: attitudes, agendas, deaths |
| `state/world_state.md` | Worlds, factions, off-screen clocks, campaign date |
| `lore/` | **Pre-established GM canon** — reference, background, secrets |
| `lore/README.md` | Lore index, canon precedence rules, spoiler convention |
| `lore/dynasty/` | House Vharadan: history, fleet, house troops |
| `lore/people/` | Deep canon for the senior NPCs (including their secrets) |
| `lore/factions/` | Rivals, patrons, and the incoming Imperial wave |
| `lore/places/` | The Hesperus Reach and the Hesperus Prime system |
| `lore/primer/` | Warhammer 40k setting-fidelity crib sheet for the GM |

## A note on spoilers

The `lore/` files contain **GM secrets** — unrevealed truths about NPCs,
worlds, and the Reach itself, kept under clearly marked `## GM secrets`
headings. The GM will never volunteer them; play uncovers them. If you are
the player: reading them is your call, but the campaign is better unspoiled.
